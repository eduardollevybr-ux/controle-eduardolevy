# Controle

Painel pessoal de gestão de banca e resultados. Reúne em um só lugar o registro das entradas, um calendário de resultados por dia e indicadores de desempenho do período.

## O que o app faz

Permite registrar entradas, acompanhar o resultado de cada dia em um calendário mensal, em reais ou em porcentagem, e consultar análises com gráficos e indicadores como ROI e taxa de acerto.

## Como foi construído

HTML, CSS e JavaScript em uma aplicação de página única. Login e sincronização dos dados com o Supabase. É um PWA: pode ser instalado no celular ou no computador como um aplicativo. A publicação é feita pelo GitHub Pages.

Projeto desenvolvido por Eduardo Levy com apoio de ferramentas de IA generativa.
